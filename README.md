# Credit Scoring

Репозиторий с решением задачи кредитного скоринга (предсказание дефолта заемщика по кредитной истории).

## Подход

Лучшее решение строится на усреднении предсказаний от трансформерных моделей, обученных на одном и том же наборе данных но с разными seed-ами для уменьшения ошибок от индивидуальных предсказаний моделей.

Архитектурно трансформер переводит дискретные значения из доступных данных в обучаемые векторные представления с помощью эмбедингов, после чего они все конкатенируются в один большой вектор, который переводится в размерность `d_model` с использованием проекции `nn.Linear`. К этому представлению добавляется в начало специальный обучаемый токен `cls` для классификации, как в моделях BERT, а также добавляется позиционная информация. Это все прогоняется через какое-то число `nn.TransformerEncoderLayer` слоев, после чего представление токена `cls` идет в голову для классификации, которая предсказывает единственное число. При обучении и инференсе предсказания модели преобразуются с помощью сигмоидной функции в число в интервале `(0; 1)` -- это и есть предсказание дефолта.

Входом для модели явлется кредитная история человека, которая собирается по полям `id` и `rn` в данных, для одного `id` в общем случае несколько продуктов, в коде берутся последние `MAX_LEN` продуктов (если столько есть, иначе сколько имеется) в порядке от самого позднего (наибольшее значение `rn`) к самому раннему, именно их количество определяет длину последовательности, которая подается на вход трансформерной модели. Для эффективной обработки используется батчирование с кастомной collate функцией.

Помимо этого для других решений использовалась модель catboost на агрегированных признаках. Для последовательности кредитных продуктов собираются статистики (mean/max/min/std/nunique для каждого признака). Модель использовалась для сравнения в качетсве бейзлайна, а также для смешивания предсказаний от разных видов моделей (в финальном решении смешивание не использовалось).

.
├── checkpoints/

├── catbooster.py         # обучение модели catboost

## Запуск

### Установка

```bash
pip install -r requirements.txt
```

### Данные

Для работы скриптов данные нужно положить в папку `data/`:

- `train_data.parquet`
- `test_data.parquet`
- `train_target.csv`

### Воспроизведение

Параметры запусков задаются в скриптах через константы, сейчас там указаны последние актуальные параметры. Чекпоинты моделей сохраняются в папку `checkpoints/`, предсказания сохраняются в `submissions/`

```bash
# сохранит обученную модель в checkpoints/catbooster_v2.cbm и
# сохранит предсказания в submissions/catboost_v2.csv
python catbooster.py
# сохранит обученные модели в checkpoints/credit_transofrmer_m{seed} и
# сохранит предсказания в submissions/transformer_megamix.csv
python transformer.py
# загрузит модели из checkpoints/ и сохранит предсказания в submissions/blend.csv
python blend_predictions.py
```
